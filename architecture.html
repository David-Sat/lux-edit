Architecture Breakdown

Target Application

Your Web App & Source

lux-edit works with any running dev server (Vite, Next.js, Webpack) or static HTML page without modifying your dependencies or configs.

  • Zero source code modifications required
  • Live reload loop triggered on agent code changes

Agent Protocol

AI Coding Agent

Coding agents like Claude Code, Cursor, and Codex connect via stdio to fetch batches and apply structured AST & Tailwind diffs.

  • Instant review retrieval with lux_get_pending_review
  • Applies verified code edits directly to source files

Tooling Layer

Injected Overlay & Proxy

The proxy streams your application on localhost:4320 and injects the Preact Shadow DOM overlay directly into the browser.

  • Context-aware toolbar with range sliders & tokens
  • Real-time WebSocket event synchronization
