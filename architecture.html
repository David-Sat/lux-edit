Model Context Protocol (MCP) Powered

LUX — Live User Experience

An isolated in-browser staging canvas that serializes visual tweaks, text rewrites, and layout mutations into structured semantic diffs for AI coding agents.

Core System Architecture

Layer 1 • Proxy

Reverse Proxy & Injector

Proxies upstream dev servers or serves static HTML files, streaming the Shadow DOM overlay script dynamically into HTML responses.

  • Zero repo pollution (no permanent files added)
  • Full WebSocket & HMR forwarding (Vite, Next.js)
  • Dynamic CSP bypass nonces
Layer 2 • In-Browser

Shadow DOM Overlay

Completely isolated Web Component (<visual-edit-overlay>) running inside Shadow DOM.

  • Floating micro-inspector with Spacing box-model
  • Inline contenteditable text editing
  • DOM child reordering, duplicate & delete
Layer 3 • Intelligence

Semantic Diff & Tailwind Mapper

Extracts structured mutation records comparing before/after snapshots and maps CSS to Tailwind utilities.

  • React Fiber source mapping (_debugSource)
  • Maps pixel values to Tailwind (p-6, mb-8, text-xl)
  • Preserves comments and component hierarchy
Layer 4 • Agent Protocol

MCP Server & Stdio Bus

Official Model Context Protocol implementation providing atomic claims and structured session batches for AI agents.

  • lux_list_sessions
  • lux_get_session
  • lux_wait_for_review

End-to-End Workflow

1. Visual Draft
Tweak styles, edit text inline, reorder nodes in browser
2. Diff Extraction
Serializes DOM mutations & resolves React/HTML source location
3. MCP Pipeline
AI Agent claims batch, reads AST delta & user instructions
4. Idiomatic Code Sync
Agent refactors repo code and notifies browser overlay
